# Zoosh brand images

Home Assistant (2026.3 and newer) and HACS read an integration's images from this folder.

| File | Size | Use |
| --- | --- | --- |
| `icon.png` / `icon@2x.png` | 256 x 256 / 512 x 512 | Square icon, transparent corners |
| `logo.png` / `logo@2x.png` | 574 x 256 / 1148 x 512 | Icon plus the "zoosh" wordmark |
| `dark_icon.png` / `dark_icon@2x.png` | same | Icon variant for dark backgrounds |
| `dark_logo.png` / `dark_logo@2x.png` | same | Logo variant with a light wordmark for dark backgrounds |

All images are original artwork made for Zoosh (the letters are hand-built strokes, no font
is used). The editable SVG sources, the design note and the regeneration scripts are in
`branding-source/` in the repository.
